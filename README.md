# BIPIA Lab

Public bilingual experiment workflow preview.

## GitHub Pages

Upload the extracted files so index.html is in the repository root. In Settings > Pages choose Deploy from a branch, main, /(root), then Save. Open the published site from the Pages settings. Add ?lang=en or ?lang=zh to select the interface language.

The public website runs a synthetic demonstration with predetermined answers. Real model experiments run through the local Python console, available from Getting started > Download local web console. The hosted preview accepts no API keys and makes no model calls.
